# Controle_de_Estoque
Sistema básico CLI para controle de estoque
# Sobre o sistema de controle de estoque
Trata-se de um sistema simples de controle de estoque, desenvolvido em Python, que visa o gerenciamento e a organização para um mercado de pequeno porte.
# Objetivo
Permitir o cadastro e gerenciamento de produtos, facilitando o controle das quantidades disponíveis no estoque.
# Funcionalidades
- Cadastro de produtos: Registra um novo produto no estoque.
- Consultar estoque: Exibe os produtos cadastrados.
- Adicionar quantidade de produtos: aumenta a quantidade disponível.
- Retirar produtos: Diminui a quantidade disponível.
- Excluir produtos: Remove um produto.
- Encerramento do sistema: Finaliza o programa.
